# Third-Party Data / Licensing Notes — WatchMan v0.1.4

WatchMan uses or can query OpenStreetMap-derived services for map tiles, geocoding, route-adjacent feature data, and camera/sensor records. OpenStreetMap data is licensed under the Open Database License (ODbL); the map displays `© OpenStreetMap contributors` attribution. Distribution must continue to comply with applicable OSM attribution and tile/service usage policies.

Transport for NSW's current Open Data catalogue identifies the Live Traffic Cameras dataset under Creative Commons Attribution. The historical direct URL present in the supplied SafeTOC source is documented for compatibility analysis but is not treated as an active WatchMan feed in this build because unauthenticated retrieval currently fails.

OSRM/Nominatim/Overpass endpoints are services operating over open data/software ecosystems; service access policies are distinct from underlying data licensing and should be reviewed before large-scale deployment.

WatchMan application code and BGGG-specific licensing terms are not assigned by this file; apply the intended project license separately.
